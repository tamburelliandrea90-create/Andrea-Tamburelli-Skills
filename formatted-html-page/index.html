formatted-html-page

Formatted HTML Page impagina testi, documenti e risultati di ricerca in una pagina HTML con titoli chiari e riquadri colorati. Puoi usarla per preparare lezioni, guide, checklist e report da pubblicare su Payhip o come pagine autonome.

Come funziona

Incolla il testo o allega il documento da impaginare. La skill organizza il contenuto in sezioni e usa i colori per distinguere obiettivi, spiegazioni, procedure, esempi e avvertenze. Se chiedi solo di impaginare, conserva il testo integrale, l’ordine, le citazioni e i link.

Quale file ricevi

  • Per Payhip o altri editor ricevi un file TXT con un frammento HTML da copiare e incollare.
  • Per una pagina autonoma puoi chiedere un file HTML completo da aprire nel browser.
